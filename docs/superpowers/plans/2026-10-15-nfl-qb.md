# NFL QB-leiðrétting: útfærsluáætlun

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mæla tvær leiðréttingar fyrir byrjunarleikstjórnanda í NFL-Elo (A: föst refsing, B: EPA-einkunn) og setja þá betri á síðuna ef hún slær núverandi líkan framvirkt.

**Architecture:** `runElo` fær valfrjálsan `GameAdjuster` sem gefur Elo-leiðréttingu á lið fyrir leik og lærir eftir leik. `lib/nfl/qbElo.ts` hefur útgáfurnar tvær. Mælingarskrifta velur stillingar á 2002-2014 og prófar á 2015-2025. Áfangi 2 (aðeins ef útgáfa stenst) tengir hana við cron, gagnagrunn og síður.

**Tech Stack:** TypeScript, vitest, tsx-skriftur, Supabase RPC, Next 16.

Spec: `docs/superpowers/specs/2026-10-15-nfl-qb-design.md`. Keyrt úr `web/`: `npx vitest run test/<skrá>`.

**Files:** Modify `web/src/lib/nfl/elo.ts`; Test `web/test/nfl-elo.test.ts`

```ts
export interface QbAdj { home: number; away: number }
/** Elo points added to each side before kickoff, and what it learns once the game is played. */
export interface GameAdjuster { before(g: EloGame): QbAdj; after(g: EloGame): void }
```
- `EloGame` fær `'home_qb_id' | 'away_qb_id'`.

- `predictGame(g, state, params, adj: QbAdj = {home:0, away:0})` leggur `adj.home − adj.away` við `diff`.

### Task 4: Útgáfa B, EPA-einkunn

**Files:** Modify `web/src/lib/nfl/qbElo.ts`; Test `web/test/nfl-qb-elo.test.ts`

```ts
export interface QbParams { c: number; a: number; t: number; n0: number; prior: number }
/** Starter EPA (passing + rushing) by `${qb_id}:${season}:${week}:${REG|POST}`. */
export type QbEpa = Map<string, number>
export const epaKey = (qb: string, season: number, week: number, gameType: string) =>
  `${qb}:${season}:${week}:${gameType === 'REG' ? 'REG' : 'POST'}`
export function ratingAdjuster(p: QbParams, epa: QbEpa): GameAdjuster & { player(id: string): number; team(club: string): number }
```
- Leikmaður: `S ← S(1−a) + epa`, `W ← W(1−a) + 1`; einkunn `(S + n0·prior)/(W + n0)`; óþekktur = `prior`.
- Lið: `T ← T(1−t) + t·epa` byrjunarmannsins; óþekkt lið byrjar í `prior`.
- `before`: `adj = c × (player(qb) − team(club))`, 0 ef id vantar.
- `after`: aðeins ef EPA-lína er til fyrir byrjunarmanninn; annars ekkert uppfært.
- [ ] Próf: nýliði fær `prior`; einkunn færist í átt að nýjum leik; `c=0` gefur 0; leikur notar ekki eigin EPA (before kallað á undan after); vantar EPA → engin breyting.
- [ ] Útfæra; keyra; commit.
