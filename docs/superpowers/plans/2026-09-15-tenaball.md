# Tenaball implementation plan

## Design
Upgrade the existing /topp10 entry point to the supplied single-screen Tenaball design. Keep the existing app shell and normalisation helper. Build a responsive navy/cyan/violet scene in HTML, CSS and SVG, with ten answer-order slots and no screenshot UI. The supplied request and reference define the design.

## Steps
1. Add tests for a pure three-life, ten-answer game with stable club IDs, explicit aliases, terminal guards, input deduplication and validated session restoration.
2. Add a source-dated UEFA club catalogue and three questions: all European champions, champions since 1992/93, and winners in both eras. Reuse existing Top 10 aliases.
3. Replace Topp10Game with the Tenaball controller, saved session, contextual feedback, result panel, help and answer reveal. Keep visual events separate from committed game state.
4. Add the pyramid, original SVG star-ball illustration, continuous 16-second scenery, one-shot answer and victory effects, mobile layout, focus handling and reduced motion.
5. Update page metadata and navigation. Run game tests, full suite and build. Exercise desktop/mobile, all outcomes, rapid submissions, reload, next round, reduced motion and two full background loops in a real browser; save screenshots.

## Verification criteria
Any ten eligible distinct clubs win. Wrong answers spend exactly one life per submission; empty/duplicate answers spend none. Session reload preserves attempts and results without celebration replay. All ten rows remain legible and keyboard input works. No animation controls game state.
